# Oru Ritual — 앱 프로토타입 (React)

하루 5분, 숨·얼굴·마음을 돌보는 웰니스 리추얼 앱의 시연용 프로토타입입니다.
React 18 + Vite로 만들었고, 서버 없이 브라우저만으로 동작합니다(기록은 각자 기기의 브라우저에 저장).

## 담긴 기능
- **5분 리추얼**: 마음 체크인 → 나에게 맞춘 리추얼 → 호흡 1분 → 페이셜 테라피 3동작 → 내 마음 어루만지기 → 리추얼 후 체크 → 전후 비교
- **맞춤 루틴**: 감정·긴장 부위로 한마디와 테라피를 추천하고, 동작을 바꿔 "내 루틴"으로 저장
- **요일별 리추얼**: 7개 테마, 오늘의 한마디 100개(요일별 순환), 페이셜 테라피 10동작 애니메이션 가이드
- **기록**: 달력, 한 줄 기록, 주간 마음·얼굴 리포트, 5주 "나의 변화 기록"
- **시연 도구**(나 탭): 4배속, 지난 5주 기록 채우기, 온보딩 다시 보기, 기록 지우기

## 내 컴퓨터에서 실행
Node.js 18 이상이 필요합니다.

```bash
npm install
npm run dev
```
브라우저에서 표시되는 주소(보통 http://localhost:5173)를 열면 됩니다.

## Vercel 배포 (둘 중 하나)

### A. GitHub 연결 (추천)
1. 이 폴더를 GitHub 새 저장소에 올립니다.
2. vercel.com → **Add New… → Project** → 저장소 선택 → **Import**
3. Framework Preset이 **Vite**로 자동 선택됩니다. 그대로 **Deploy**.
   - Build Command: `npm run build` · Output Directory: `dist`
4. 배포가 끝나면 `https://<프로젝트명>.vercel.app` 링크로 누구나 휴대폰에서 열 수 있습니다.

### B. Vercel CLI
```bash
npm install -g vercel
vercel          # 처음 한 번 로그인 후 미리보기 배포
vercel --prod   # 정식 주소로 배포
```

## 폴더 구조
```
src/
  App.jsx            화면 전환·리추얼 흐름·상태 관리
  data/content.js    요일 테마, 한마디 100개, 테라피 10동작, 감정·긴장 부위, 시연 데이터  ← 문구 수정은 여기서
  lib/               날짜·추천 로직, 소리/진동, 타이머, 저장
  components/        캐릭터 얼굴(마사지 가이드), 공통 UI, 잠금화면·동작 바꾸기 시트
  screens/           14개 화면
  styles.css         디자인(아이보리 그라데이션, 다크 모드, 어절 단위 줄바꿈 포함)
```

## 참고
- 감정·마음의 무게·표정 긴장은 셀프케어 기록이며 의료적 진단이 아닙니다.
- 표정 스캔·거울 모드·QR 등록·스토어 연결은 시연용 안내 문구로 표시됩니다.
